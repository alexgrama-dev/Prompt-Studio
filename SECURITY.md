# Security Policy

## Supported version

Security fixes are applied to the latest release and the `main` branch.

## Report a vulnerability privately

Please do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/alexgrama-dev/Prompt-Studio/security/advisories/new)
so the report, reproduction steps, and any sensitive details stay private.

Include the affected version, the impact, and the smallest reproducible example
you can safely share. You should receive an acknowledgement within seven days.

## Scope

Useful reports include unintended file access or modification, accidental
network requests, credential exposure, unsafe prompt parsing, and ways to bypass
an explicit confirmation before a destructive action.
