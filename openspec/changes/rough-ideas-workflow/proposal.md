## Why

The current Seed Inbox is hidden inside Enhance Prompt. It creates a new
record for the same thought each time, hides invalid Markdown as an empty
inbox, and cannot edit or repair an idea. Local capture also disappears when
model enhancement is unavailable. Its generated first-line labels are not
useful titles. These limits make it poor as a daily inbox.

## What Changes

- Replace the user-facing Seed Inbox name with Idea Studio.
- Make Prompt Studio, Enhance Prompt, and Idea Studio the three view commands
  shown in Raycast.
- Add one top-level Idea Studio command for local capture, search, edit, repair,
  deletion, and explicit transfer to Enhance Prompt.
- Generate a concise idea title with the active OpenAI provider, validate it,
  and let the user review it before the idea is saved.
- Offer an explicit title-generation action for earlier ideas whose titles were
  not generated by AI.
- Keep capture available without a provider, model request, project scan, or
  network request.
- Make repeated exact saves return the existing idea.
- Group valid ideas as Ready to Enhance or Enhanced without hiding them when
  enhancement history cannot load.
- Show invalid idea files under Needs Repair with file-recovery actions.
- Add an explicit, previewed, confirmed migration that consolidates historical
  exact duplicates while preserving their identifiers as aliases for existing
  enhancement and prompt links.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `prompt-enhancement`: visible Idea Studio capture, AI titles, repair, reuse, editing,
  duplicate consolidation, and seed-to-result traceability.

## Impact

- Raycast extension: one `idea-studio` command and smaller launch-context
  handoffs to `enhance-prompt`.
- The encrypted OpenAI key moves from one command preference to an
  extension-wide password preference so Enhance Prompt and Idea Studio use the
  same key. Prompt Studio does not copy it to local storage or a file.
- Shared storage: existing `.seeds` Markdown remains the recoverable source of
  truth; idea records may gain validated title provenance and a consolidated
  record may gain prior seed identifiers.
- Existing enhancement-history and prompt records are not rewritten. Their old
  seed identifiers resolve through the consolidated record.
- Adds no dependency, database table, provider, activation order, or
  default-state change. AI title generation uses the existing OpenAI provider
  only after an explicit user action.
- The migration never runs on launch. It requires a visible preview and
  confirmation.
